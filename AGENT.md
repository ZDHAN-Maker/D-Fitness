# Agent Guidelines & Workflow Rules

## Aturan Utama (Wajib Dipatuhi)
1. **JANGAN UBAH APAPUN SEBELUM KONFIRMASI DENGAN USER**
   - Sebelum melakukan modifikasi kode, penambahan fitur, atau penghapusan file, jelaskan rencana kerja terlebih dahulu dan minta persetujuan/konfirmasi dari user.
2. **SELALU KONFIRMASI SEBELUM MULAI KERJA**
   - Setiap langkah atau task baru harus dikonfirmasikan dan disetujui terlebih dahulu oleh user sebelum eksekusi dimulai.
3. **JANGAN COMMIT DAN PUSH TANPA PERSETUJUAN USER**
   - Dilarang keras menjalankan perintah `git commit` atau `git push` secara mandiri atau otomatis tanpa instruksi/izin eksplisit dari user.
4. **SELALU CONTRIBUTOR ADALAH USER, BUKAN AI / ASSISTANT**
   - Semua kontribusi, git commit author/committer wajib atas nama User (`Dan <uprise419@gmail.com>`), BUKAN AI.
   - Tidak ada tanda tangan atau atribusi commit yang mengatasnamakan bot/AI.
